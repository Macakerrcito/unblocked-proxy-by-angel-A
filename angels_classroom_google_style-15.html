Liquid glass

How the glass works

Only active on Max graphics. Rather than one flat blur everywhere, surfaces use four strengths: subtle for small controls like buttons and search fields, medium for cards, panels and link rows, strong for the fixed top bar and sidebar, and strongest for the sign-in card. Each layer adds saturation, a top highlight, a pointer-tracked reflection and a soft moving sheen so it visibly sits above whatever wallpaper is behind it.

Particles

Falling blossoms

Only active on Max graphics. Runs on canvas, not hundreds of DOM elements, in three size/speed depth layers. The particle count adapts to your device's CPU cores, and the whole effect pauses automatically when the tab is hidden or reduced motion is on.

Accessibility

Accessibility

Every button here is a real <button> with keyboard focus and, where the label isn't visible text, an aria-label. The system Reduced Motion preference is respected everywhere — it also stops the particle layer, startup animation and scroll reveals. Esc closes the mobile menu, and PS3/Switch layouts support arrow-key + Enter navigation.

Performance

Performance

Search inputs are debounced, the particle loop and live wallpaper both pause via the Page Visibility API when you switch tabs, and switching graphics or appearance settings only re-applies theme classes rather than re-rendering the whole page.
